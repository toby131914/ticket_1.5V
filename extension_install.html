搶票助手返回搶票系統

下載與安裝搶票助手

使用電腦版 Chrome 完成安裝，再開啟搶票系統。首次設定後，使用同一個瀏覽器即可繼續使用。

下載擴充功能 ZIP 已安裝，前往連線設定

下載後請先解壓縮；Chrome 無法直接載入 ZIP。請保留解壓縮後的資料夾。

01解壓縮下載檔案

在 ZIP 上按右鍵，選擇「解壓縮全部」。開啟解壓縮後的資料夾，確認包含下列四個檔案：

manifest.jsonbackground.jspopup.htmlpopup.js

02載入 Chrome 擴充功能

chrome://extensions

  1. 將上述網址貼到 Chrome 網址列，按 Enter。
  2. 開啟右上角的「開發人員模式」。
  3. 點選「載入未封裝項目」。
  4. 選擇直接包含 manifest.json 的資料夾。

看到「Google Forms Sniper」且開關已啟用，就代表載入成功。

03連線到搶票系統

從 Chrome 擴充功能管理頁複製「Google Forms Sniper」下方的 ID。請使用自己電腦顯示的 ID。

ID 為 32 個 a 到 p 的小寫英文字母。

進入系統後，請確認顯示「搶票助手已連線」。輸入表單網址並先執行「登入檢查」，完成 Google 登入後再設定時間。

安裝遇到問題

載入時顯示找不到 manifest.json

請先解壓縮 ZIP，並選擇直接包含 manifest.json 的那一層資料夾，不要選 ZIP 或外層資料夾。

系統顯示找不到擴充功能

確認擴充功能已啟用，重新複製自己的 ID，回到上方連線設定。若剛安裝，請重新整理搶票系統頁面。公司或學校管理的 Chrome 可能限制安裝。

如何更新擴充功能？

重新下載 ZIP，將新檔案解壓縮並覆蓋原本資料夾內的四個檔案。在 chrome://extensions 點選該擴充功能的「重新載入」按鈕，再重新整理搶票系統。若移除後重新安裝，請重新確認 ID。

手機可以使用嗎？

本安裝流程適用於電腦版 Chrome，手機版 Chrome 無法用這個方式載入擴充功能。
